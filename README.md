# 🪙 Crypto Tracker v1.0

Простое и удобное десктопное приложение на Python для отслеживания актуальных курсов популярных криптовалют в режиме реального времени.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-orange.svg)
![API](https://img.shields.io/badge/API-CoinGecko-green.svg)

---

## 🚀 Возможности

- 📊 **Отслеживание топовых монет:** Bitcoin (BTC), Ethereum (ETH), Solana (SOL), Binance Coin (BNB), Ripple (XRP).
- 💱 **Мультивалютность:** Быстрое переключение отображения цен в **USD ($)**, **EUR (€)** и **RUB (₽)**.
- ⚡ **Автообновление:** Курсы автоматически пересчитываются при смене валюты из выпадающего списка.
- 🕒 **Статус и время:** Отображение точного времени последнего успешного обновления данных.
- 🛡 **Защита от сбоев:** Обработка ошибок при отсутствии подключения к интернету или недоступности API.

---

## 🛠 Технологии и библиотеки

* **Python 3.8+**
* **Tkinter / ttk** — графический интерфейс пользователя (GUI).
* **Requests** — отправка HTTP-запросов к API.
* **CoinGecko API v3** — источник данных о курсах криптовалют.
